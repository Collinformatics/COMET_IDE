COmprehensive Motif Evaluation Toolkit

Predict Activity

Use a Substrate Profile to predict Substrate Activity. Activity scores are made from a prediction matrix that is evaluated by comparing AA frequencies in the Substrate Profile to the Background dataset.
Multiple Substrate Profiles can be combined into an averaged set.
? To only predict activity:
  AVLQSGFR, VTFQSAVK, ...

To predict activity and compare to experimental values:
  AVLQSGFR:55, VTFQSAVK:20, ...
? Combine N number of profiles.
? Number of AAs in the substrate.
? Number of AAs in the recognition site.
? Background count matrix.
Acceptable file extension: .csv
